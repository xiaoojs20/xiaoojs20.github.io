# 个人网站维护说明

本站基于 Liquid Stack 1.2.0（上游提交 309687af65561ecc94e42daea3b163a73775a86b），采用 Hugo Extended 0.161.0 构建。模板和 Hugo Theme Stack 的许可证随源码保留。

- `hugo.yaml`：站点名称、个人简介、头像路径和社交链接。
- `content/page/about/index.zh.md`：关于我。
- `content/page/life/index.zh.md`：生活记录。
- `content/page/notes/index.zh.md`：随笔。
- `data/photo-wall/`：照片墙数据；当前照片为模板示例。
- `assets/img/avatar-personal.jpg`：当前头像。
- `layouts/home.html`：首页卡片。

本地预览：在本目录运行 `hugo server`。构建时在仓库根目录运行 `hugo --source liquid-preview --destination /tmp/xiaoojs20-site-build --minify`，将生成文件同步到仓库根目录后提交并推送 `master`。正式更新之前应检查链接及生成结果。旧站保存在改版之前的 Git 提交历史中。

双语内容：英文主页为 `/`，中文主页为 `/zh/`；各栏目使用同目录下的 `index.zh.md` 和 `index.en.md` 分别维护。首页文案在 `layouts/home.html` 中按语言切换。

Coffee Chat：预约链接和嵌入地址位于 `hugo.yaml` 的 `params.coffeeChat`，预约区位于“关于我”页面，通过 `layouts/_shortcodes/coffee-chat.html` 共用中英文布局。

关于我的经历时间线：修改 `data/experience.yaml` 中对应的中英文内容。


旅行地图：访问 `/travel/` 或 `/zh/travel/`。真实地点维护在 `data/travel.yaml` 的 `visits` 列表里，`group` 对应同文件 `groups` 中的省份或国家；分组按 `groups` 中的 `order` 排序，组内按 `visits` 的顺序显示；`demo` 是明确标记的展示示例，不计入地点数量。每个地点可按下面格式添加，照片文件先放到 `static/img/travel/`，路径使用 `/img/travel/文件名.jpg`；不填照片也能展示地点。经纬度、地点名和照片都将公开发布，请只填写希望公开的信息。修改后按上面的 Hugo 构建和发布流程更新。

```yaml
visits:
  - id: unique-place-id
    group: fujian
    name: City name
    nameZh: 城市名
    region: Region or country
    regionZh: 所属地区或国家
    latitude: 30.0
    longitude: 105.0
    date: "2026-10"
    description: A short memory.
    descriptionZh: 一句旅途记录。
    photos:
      - src: /img/travel/example.jpg
        caption: Photo caption
        captionZh: 照片说明
```

地图使用本地打包的 Leaflet 和矢量边界：背景是 Natural Earth，已记录地区轮廓来自 OpenStreetMap（ODbL），数据保存在 `static/data/travel-map/`。新增地点后还需补充匹配的行政区 GeoJSON（`properties.id` 与地点 ID 相同）；未补边界时仍会显示地点标记和相册。地图数据归属显示在地图上。

地点图标：所有地点统一显示为图钉，样式由 `static/css/travel-map.css` 控制。

旅行分组：给新地点填写已有的 `group`；新增省份或国家时，在 `data/travel.yaml` 的 `groups` 中添加中英文名称和排序数字 `order`。没有配置分组的地点会显示在「其他地点」中。

随笔：中文原稿放在 `content/post/<文章标识>/index.zh.md`，在 front matter 中设置 `note: true`、`hidden: true`，随笔列表会自动收录，首页不展示该条目；文章和随笔列表仍然是公开的。`date` 保存首次发布时间和时区；如需单独标记写作月份，可设置 `written: "2026.10"`；后续编辑正文时保留原 `date`，如需显示修改时间可添加 `lastmod: "2026-10-30T12:00:00+08:00"` 并填写实际修改时间。更新后重新构建并推送。英文列表会显示尚无英文译本的中文文章并标注语言；需要英文译文时可在同目录新增 `index.en.md`。文章仅有中文时，切换英文会返回英文随笔列表。
