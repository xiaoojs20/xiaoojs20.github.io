# 买车 🆚 打车：维护与核对

双语文章位于 content/post/car-vs-taxi/index.zh.md 和 index.en.md；两者共用 shortcode、模型模块、UI 模块和 CSS。路径分别为 /zh/p/car-vs-taxi/ 和 /p/car-vs-taxi/。随笔列表与首页最近更新自动收录。

## 计算合同

当前模型版本为 2026-11-09.1。默认上海、Model Y 后轮驱动版 263,500 元、持有 5 年、年出行 10,000 km。燃油参考车型为 2027 款途观 L Pro 380TSI 两驱领航版 251,800 元。km 是等效打车需求，自驾年里程为 detour × km，累计自驾里程再乘 years。参数输入的百分数在公式中除以 100。

保险、保养、轮胎、维修和折旧都由公式计算。停车取月度报价，车船税取当地规则下的实际年税额；这些外部价格不能由车价推定。电费、油费和通行费按实际自驾里程计算。一次性费用分摊到持有期，资金成本还会使用期末残值。

- 残值含车龄、车价与累计里程。车龄锚点是年龄因素的情景假设，非市场统计。保值率校准采用 r(t)^(100/界面校准值)，可提高或降低保值率且不超过车价；0 按零残值处理。已删除单列的 extraWear，避免再加一笔里程折旧。
- 保险采用第 0、1、2……年保单起点车值，最后非整年按使用期分摊。damageQuote 仅为新车车损险分项，交强险与三者险另列。里程风险以自驾 10,000 km/年为参考。它是情景预算，不是保险公司费率预测。
- 保养单次费用和轮胎单价可由 250,000 元参考车价的幂函数估算，或以实际单次报价覆盖。次数/耗用量取时间与里程触发量中的较大者，可以是小数。
- 轮胎是维持基准车况的连续耗用预算，不是整套换胎的现金时间表。未另加初装轮胎采购费；残值与维修预算应采用同一车况口径。
- 维修为车价比例 × 质保/车龄敞口 × 年里程风险，属于准备金，不是确定维修金额。
- 所有系数均为可修改假设，未做车型级标定。单次服务、轮胎价格的幂函数不表示某车价能唯一确定零件价格或维护成本。

## 求交点与图表

现在的成本函数为非线性函数，不能再使用旧版 F、v、w 两段线性临界公式。calculate 返回 carAt、taxiAt、at，按同一模型求值。年出行里程求解范围是 0–200,000 km。有效参数域内各成本项的单位需求成本非增，可以在端点确定包围区间后用二分法求唯一符号交点。范围内无交点时只能报告范围内结果，不能称永远无有限交点。

结果区同时显示里程、车价和持有年限三张图。车价和年限曲线绘图时调用 calculate(p, { solveCrossings: false })，避免每个绘图点重复求年里程交点。图上空心圆是当前用量，紫点是费用相等处。CSV 包含三张图的采样，含实际输入与交点。

页面加载时根据默认参数或分享链接计算结果。参数、预设及费用勾选变动后自动重算。无效输入暂时隐藏结果，修正后自动恢复。重置会恢复上海 Model Y 算例并重绘图表。切换动力会载入参考车型参数，清空车损险、保养和轮胎报价，恢复默认购置税口径。切换城市会载入区域费用示例。
