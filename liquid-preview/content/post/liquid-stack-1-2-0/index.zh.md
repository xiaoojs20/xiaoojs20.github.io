Liquid Stack 1.2.0 重点改进手机导航，并加入数个可复用、可按需移除的组件，同时保持 Stack v4 原有的内容结构。

## 统一的手机个人信息顶栏

普通内容页面现在新增手机顶栏。向上滚动时，头像与网站名称会移动到屏幕顶部的固定顶栏中，同时保留深浅色切换、语言切换和菜单入口。

搜索页面会在出现结果、页面可以滚动后显示顶栏，并把搜索框保留在顶栏下方。

![统一的手机个人信息顶栏](/img/liquid-stack-1-2-0/mobile-profile-bar.png)

## 适合触控操作的浮动导航

较长的关于页面与简历页面可以在手机上保留章节导航。点击按钮展开菜单，选择章节后自动收起，点击菜单外部也会关闭。

其他较长的展示页面也可以复用这套响应式导航方式。

## 可选产品目录演示

新增一个使用虚构数据的小型产品目录，用于演示 Hugo 数据如何驱动可搜索、可筛选的展示页面。四条示例记录包含：

- 中英文数据；
- 名称与介绍搜索；
- 状态筛选和表格排序；
- 分类展开与收起；
- 桌面表格和手机卡片布局。

这个组件刻意保持简洁。不需要产品目录的网站可以删除对应内容、数据和布局文件，不会影响博客功能。

## Web App 基础适配

模板现在提供 Web App Manifest、192 与 512 像素安装图标、Apple 独立窗口元数据，以及与浅色和深色模式匹配的浏览器主题色。

这些内容构成网站添加到主屏幕时所需的基础元数据。1.2.0 暂未加入 Service Worker 或离线缓存。

## 可选 Waline 安全增强

可选的 Waline 集成增加了基于 Turnstile 的上传会话与评论验证前端接口。该功能默认关闭，因为只有兼容后端实现对应验证接口后，这些检查才能形成完整的安全保护。

后端接口约定记录在 `docs/waline-secure-uploads.md`。

## 文章写作标识

文章现在可以选择声明以下两种状态之一：

```yaml
writingMode: human
```

```yaml
writingMode: aigc-assisted
```

文章页脚和 Sveltia CMS 会显示对应的双语标识。不填写该字段时，文章继续使用原来的展示方式。

## 兼容性

1.2.0 没有计划中的破坏性变更。现有 Markdown 文章、Stack 分类与标签、双语内容包和 Hugo 地址结构均保持不变。

完整功能说明请查看[欢迎使用 Liquid Stack](/zh/p/welcome-to-liquid-stack/)。
